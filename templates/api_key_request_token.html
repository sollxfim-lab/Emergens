Developer API Access
Authentication
Sign in with your Emergens dashboard credentials. A bearer token (valid for 1 hour) will be generated and used for all subsequent API calls on this page.
Paste an API key generated from Dashboard → API Keys → Generate New Key. API keys are long-lived and do not expire.
Account
Getting Started
1
AuthenticateUse your username + password above to receive a bearer token. Or paste an existing API key.
2
Set the headerSend Authorization: Bearer <token> on every request.
3
Call an endpointStart with POST /api/scan/start — see the reference below.
4
Poll for resultsCheck /api/scan/{job_id}/status every second until it completes.
Endpoint Reference
MethodEndpointDescription
POST/api/tokenExchange username + password for a bearer token (valid 1 hour).
GET/api/meVerify a token or API key; returns account info.
POST/api/scan/startStart a scan job. Returns a job_id.
GET/api/scan/{job_id}/statusPoll a scan job for progress and results.
