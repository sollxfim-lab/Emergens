Authentication
Sign in with your Emergens dashboard credentials. A bearer token (valid for 1 hour) will be generated and used for all subsequent API calls on this page.
Paste an API key generated from Dashboard → API Keys → Generate New Key. API keys are long-lived and do not expire.
Account
Getting Started
1
Authenticate Use your username + password to receive a bearer token, or paste an existing API key.
2
Set the header Send Authorization: Bearer <token> on every request.
3
Call an endpoint Start with POST /api/scan/start — see the reference below.
4
Poll for results Check /api/scan/{job_id}/status every second until complete.
Endpoint Reference
MethodEndpointDescription
POST /api/token Exchange username + password for a bearer token (valid 1 hour).
GET /api/me Verify a token or API key; returns account info.
POST /api/scan/start Start a scan job. Returns a job_id.
GET /api/scan/{job_id}/status Poll a scan job for progress and results.
